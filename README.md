# 🔗 Sholinks
Um serviço simples  e eficiente para encurtar URLs longas, desenvolvido em Go.

## 🧩 Tecnologias utilizadas
- **Go 1.25+**
- **NanoID**
- **Postgres**
- **dotenv (para variáveis de ambiente)**
- **chi (para router)**
- **Bibliotecas auxiliares listadas em requirements.txt**
